Bukti #4: Puzzle Diagram Tali Zhao Shuang (5-12-13)

📖 Pengenalan: Puzzle Geometri dari Tiongkok Kuno

Bayangkan sebuah persegi besar dengan sisi c = 13. Di setiap sisinya, kita letakkan satu segitiga siku-siku (kaki a = 5 dan b = 12) sehingga hipotenusanya menempel tepat pada sisi persegi. Keempat segitiga ini sama persis, dan titik sudut siku-sikunya menghadap ke dalam. Hasilnya: empat segitiga tersebut menyisakan sebuah persegi kecil di tengah dengan sisi (b − a) = 7. Dengan menghitung luas persegi besar dengan dua cara berbeda, kita peroleh a² + b² = c². Seperti puzzle yang elegan!

📜 Sejarah: Metode ini dikenal sebagai Xian Tu (Diagram Tali) oleh matematikawan Tiongkok kuno Zhao Shuang (abad ke-3 M) dalam karyanya Zhou Bi Suan Jing. Satu gambar cukup untuk membuktikan teorema tanpa kata-kata!

Langkah 1: Persegi besar sisi c = 13 → luas c² = 169
Langkah 2: 4 segitiga siku-siku (kaki 5 & 12) masing-masing luas ½·5·12 = 30
Langkah 3: Rongga tengah = (b−a)² = (12−5)² = 7² = 49
Langkah 4: Total = 4·30 + 49 = 120 + 49 = 169 ✓
Langkah 5: Terbukti! c² = 4·(½ab) + (b−a)² → a² + b² = c² → 25 + 144 = 169 ✓

📐 Perhitungan Lengkap (Aljabar + Angka)

Rumus umum:
c² = 4·(½ab) + (b−a)²
Substitusi a=5, b=12, c=13:
13² = 4·(½·5·12) + (12−5)²
169 = 4·30 + 7²
169 = 120 + 49
169 = 169 ✓
Pembuktian aljabar (umum):
c² = 4·(½ab) + (b−a)²
   = 2ab + (b² − 2ab + a²) ← ekspansi (b−a)²
   = 2ab + b² − 2ab + a²
   = a² + b² ← 2ab saling menghilangkan
∴ a² + b² = c² → 5² + 12² = 13² → 25 + 144 = 169 ✓ TERBUKTI!

Kalender Pythagoras 2027 • April • Kelompok 2 • Level: Dasar

Penjelasan: Persegi sisi c = 13 memuat tepat 4 segitiga siku-siku (kaki a = 5, b = 12; hipotenusa = sisi persegi) dan satu rongga persegi dengan sisi (b−a) = 7. Hitung luas persegi besar dengan dua cara:

  • Cara 1: langsung → c² = 13² = 169
  • Cara 2: 4 segitiga + rongga → 4·(½·5·12) + (12−5)² = 120 + 49 = 169

Secara umum (aljabar):

c² = 4·(½ab) + (b−a)²
   = 2ab + (b² − 2ab + a²)   ← ekspansi (b−a)²
   = 2ab + b² − 2ab + a²
   = a² + b²                     ← 2ab saling menghilangkan
c² = 4·(½ab) + (b−a)² → 169 = 120 + 49 → 169 = 25 + 144 ✓ TERBUKTI!
KESIMPULAN: a2 + b2 = c2 │ "Jumlah kuadrat sisi tegak sama dengan kuadrat sisi miring (sisi terpanjang)"
