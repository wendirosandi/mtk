📖 Pengenalan: Trapesium Sang Presiden

Tahun 1876, James A. Garfield (kelak Presiden AS ke-20) menemukan bukti elegan: sebuah trapesium siku-siku BERDIRI dengan sisi sejajar a = 8 (atas) dan b = 15 (bawah) serta tinggi (a+b) = 23. Trapesium ini tersusun pas dari dua segitiga siku-siku kongruen (kaki a & b) plus satu segitiga siku-siku sama kaki (kaki c & c). Menghitung luasnya dengan dua cara langsung menghasilkan a² + b² = c².

🎩 Fakta menarik: bukti ini dipublikasikan Garfield di New England Journal of Education — tetap favorit kelas karena hanya memakai rumus luas trapesium & segitiga.

🎬 Animasi Interaktif (Step-by-Step)

Langkah 0 dari 5 — Klik "▶ Langkah" untuk memulai
Langkah 0: Stage kosong — siap menyusun trapesium berdiri
Langkah 1: Trapesium berdiri: sisi sejajar a = 8 (atas) & b = 15 (bawah), tinggi (a+b) = 23
Langkah 2: 3 segitiga menunggu di luar: 2 siku-siku (kaki 8 & 15) + 1 sama kaki (kaki 17 & 17)
Langkah 3: Ketiganya digeser masuk — trapesium terisi penuh tanpa celah & tumpang-tindih
Langkah 4: Di titik (0, a) dua hipotenusa c saling tegak lurus → segitiga tengah siku-siku sama kaki
Langkah 5: Dua cara hitung luas sama → (a+b)² = 2ab + c² → 529 = 240 + 289 ✓ → a² + b² = c²
📐 Perhitungan Luas (a=8, b=15, c=17)
Cara 1 (rumus trapesium): L = ½·(a+b)·tinggi = ½·23·23 = 264,5
Cara 2 (jumlah 3 segitiga): ½·8·15 + ½·8·15 + ½·17·17
   = 60 + 60 + 144,5 = 264,5
Samakan ×2: (a+b)² = 2ab + c² → 529 = 240 + 289 = 529
Kurangi 2ab: a² + b² = c² → 64 + 225 = 289
✓ Terbukti: c² = a² + b² → 289 = 64 + 225

×2: (a+b)² = 2ab + c² → 529 = 240 + 289 ✓
∴ a² + b² = c² → 64 + 225 = 289
(a+b)² = 2ab + c² → 23² = 240 + 289 → 529 = 529 ✓ TERBUKTI!
