# Fixture Import (Fiktif)

Semua nama, username, nilai, dan sekolah di folder ini **fiktif**.
Jangan mengganti dengan data pribadi/sebenarnya di repository.

Urutan pemakaian:

1. `sekolah.csv` (hanya memperbarui sekolah yang sudah ada)
2. `tahun_pelajaran.csv`
3. `kelas.csv`
4. `mata_pelajaran.csv`
5. `guru.csv` (akun dibuat server, password tampil sekali)
6. `siswa.csv`
7. `wali_kelas.csv`
8. `penugasan_guru.csv`
9. `keanggotaan_siswa.csv`
10. `kategori_siswa_umum.csv`
11. `kategori_siswa_mapel.csv`

Template modul/materi, asesmen, soal, bank soal, dan nilai historis juga sudah
aktif. Contohnya dapat dibuat dari tombol **Unduh Template** di halaman
`admin-import` (jangan menambahkan data pribadi ke repository).
